# Short Video Hook Generator

Generates short video hooks, first 3-second lines, title options, pattern interrupts, and CTAs.

## Suitable Scenarios

- TikTok hooks
- Xiaohongshu video openings
- Reels ideas
- YouTube Shorts intros
- A/B hook testing

## Steps

1. Provide topic, platform, audience, content type, message, tone, length, CTA, and avoid list.
2. Generate hook variants.
3. Select variants for testing.
4. Remove misleading claims.

## Input Fields

Topic, platform, audience, content type, core message, tone, length, CTA, things to avoid, and language.

## Output Fields

Hooks, first 3-second lines, titles, pattern interrupts, curiosity gaps, pain-point versions, contrarian versions, CTA options, A/B tests, and risky wording.

## Common Mistakes

- Making hooks too long
- Overpromising outcomes
- Using misleading curiosity gaps

## Compliance Reminder

Do not use fake data, fake results, fake urgency, or deceptive clickbait.
