# Skill: short-video-hook-generator

## 中文注释

这个 skill 用于短视频开头 Hook 生成，适合 TikTok、小红书、Reels、Shorts 等平台。Hook 要短、清楚、有进入感，但不能制造恶意误导、虚假夸张承诺、虚假数据或无法兑现的结果。

## Purpose

Generate short video hooks, titles, opening lines, pattern interrupts, curiosity gaps, contrarian angles, and CTAs.

## Best for

Short video creators, Xiaohongshu creators, educators, ecommerce creators, and personal brand builders.

## Not for

Misleading clickbait, fake results, fake data, harassment, shock content, or manipulative claims.

## Input

- Topic
- Platform
- Target audience
- Content type
- Core message
- Tone
- Length
- CTA
- Things to avoid
- Language

## Output

1. Hook options
2. First 3-second opening lines
3. Title options
4. Pattern interrupt ideas
5. Curiosity gap versions
6. Pain-point versions
7. Contrarian versions
8. CTA options
9. A/B testing suggestions
10. Risky wording to avoid

## Process

1. Identify the audience's immediate reason to watch.
2. Generate multiple hook types.
3. Adapt wording to platform and length.
4. Provide CTA and A/B testing suggestions.
5. Flag risky or misleading wording.

## Quality Bar

- Hooks are short and strong.
- Openings work in the first seconds of video.
- Provides multiple variants.
- Avoids fake or exaggerated promises.
- Avoids maliciously misleading framing.
- Adapts to TikTok, Xiaohongshu, Reels, Shorts, and similar platforms.

## Example Input

Topic: how I use Codex to turn an app idea into a prototype
Platform: TikTok and Xiaohongshu
Target audience: solo app builders
Core message: AI can speed up early prototyping when paired with clear product thinking

## Example Output

Hook option: I stopped starting app ideas in Xcode first. Now I start with this AI workflow.

## Safety / Compliance Notes

Do not fabricate results, income, user numbers, engagement, or platform performance. Avoid deceptive clickbait.
