# Personal Brand Positioning

Helps creators define personal brand positioning, audience, content pillars, voice, and first content ideas.

## Suitable Scenarios

- Personal IP planning
- Creator niche selection
- Platform profile rewrite
- First content strategy
- Indie developer or educator positioning

## Steps

1. Provide creator background and expertise.
2. Add target audience, platform, goals, tone, and topics.
3. Generate positioning and content pillars.
4. Review all claims before publishing.

## Input Fields

Creator background, expertise, audience, platform, goals, tone, topics, avoid list, references, and language.

## Output Fields

Brand summary, audience profile, positioning statement, content pillars, unique angle, tone, focus topics, avoid topics, bio options, headlines, and content ideas.

## Common Mistakes

- Targeting everyone
- Using vague positioning slogans
- Inventing achievements or audience size

## Compliance Reminder

Use only real creator facts. Do not fabricate credentials, followers, income, brand deals, or case studies.
