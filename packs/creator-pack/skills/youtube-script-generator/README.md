# YouTube Script Generator

Generates YouTube titles, hooks, script structure, chapters, script drafts, B-roll, on-screen text, CTA, thumbnail text, and descriptions.

## Suitable Scenarios

- Tutorial videos
- Creator essays
- Product explainers
- AI tool walkthroughs
- Personal brand long-form content

## Steps

1. Provide topic, audience, length, style, message, key points, references, CTA, and language.
2. Generate structure and script.
3. Review factual claims and sources.
4. Adapt script to your actual voice.

## Input Fields

Topic, target audience, length, channel style, core message, key points, references, CTA, and language.

## Output Fields

Titles, hook, structure, chapter outline, script, B-roll, on-screen text, CTA, thumbnail text, and description.

## Common Mistakes

- Using invented citations
- Writing for reading instead of speaking
- Making misleading thumbnail promises

## Compliance Reminder

Verify references, facts, copyright permissions, and disclosure requirements before publishing.
