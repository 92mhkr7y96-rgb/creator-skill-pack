# Skill: youtube-script-generator

## 中文注释

这个 skill 用于 YouTube 长视频脚本生成，帮助创作者组织标题、开头、章节、口播稿、B-roll、屏幕文字、CTA 和描述。不能编造引用来源、数据、案例、经历或误导性标题缩略图。

## Purpose

Generate YouTube scripts, structure, openings, chapters, B-roll ideas, on-screen text, CTA, thumbnail text, and descriptions.

## Best for

YouTube educators, personal brand creators, indie developers, AI tools channels, and product explainers.

## Not for

Fake sources, misleading thumbnails, plagiarized scripts, fabricated case studies, or guaranteed growth claims.

## Input

- Video topic
- Target audience
- Video length
- Channel style
- Core message
- Key points
- References
- CTA
- Language

## Output

1. Video title options
2. Opening hook
3. Video structure
4. Chapter outline
5. Full script draft
6. B-roll suggestions
7. On-screen text ideas
8. CTA
9. Thumbnail text ideas
10. Description draft

## Process

1. Define the promise and audience value.
2. Build a clear video structure and chapters.
3. Draft a spoken script.
4. Add B-roll, on-screen text, CTA, thumbnail text, and description.
5. Flag unsupported sources or misleading framing.

## Quality Bar

- Structure is clear.
- Opening quickly explains viewer value.
- Script works as spoken content.
- Does not invent references.
- Avoids misleading titles and thumbnails.
- Provides chapters and visual prompts.

## Example Input

Video topic: building an iOS app prototype with Codex
Target audience: solo app builders
Video length: 8 minutes
Core message: use AI to accelerate iteration, not replace product thinking

## Example Output

Opening hook: Most app ideas die before the first usable prototype. In this video, I will show a practical AI-assisted workflow for getting to that first prototype faster.

## Safety / Compliance Notes

Do not fabricate sources, case studies, viewer results, income, platform performance, or expert credentials. Avoid misleading thumbnails.
