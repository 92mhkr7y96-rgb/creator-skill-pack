# X Thread Generator

Generates X/Twitter threads with headlines, openings, tweet-by-tweet drafts, takeaways, strong lines, CTAs, and short versions.

## Suitable Scenarios

- Opinion threads
- Founder lessons
- AI tools breakdowns
- Product-building stories
- Personal brand thought pieces

## Steps

1. Provide topic, audience, opinion, supporting points, tone, length, CTA, and language.
2. Generate the thread.
3. Verify all claims and examples.
4. Adapt to your real voice before publishing.

## Input Fields

Topic, audience, main opinion, supporting points, tone, thread length, CTA, and language.

## Output Fields

Headline, opening tweet, structure, tweet draft, takeaways, strong lines, CTA, alternative openings, short version, and risky wording.

## Common Mistakes

- Making every tweet too long
- Starting without a clear opinion
- Inventing data or personal experience

## Compliance Reminder

Do not fabricate metrics, stories, testimonials, income, followers, or audience feedback.
