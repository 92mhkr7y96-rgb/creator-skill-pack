# Skill: x-thread-generator

## 中文注释

这个 skill 用于 X/Twitter 长帖生成，帮助创作者把观点、经验和教程整理成连续可读的 thread。输出不能编造数据、案例、经历、收入、粉丝反馈或平台表现，适合个人品牌表达但必须保持真实。

## Purpose

Generate X/Twitter threads with clear opinions, structure, tweet-by-tweet drafts, strong lines, and CTAs.

## Best for

Personal brand creators, indie developers, educators, founders, AI tools creators, and product storytellers.

## Not for

Fake data, fake experiences, fake engagement, plagiarized thought leadership, harassment, or deceptive growth tactics.

## Input

- Topic
- Audience
- Main opinion
- Supporting points
- Tone
- Thread length
- CTA
- Language

## Output

1. Thread headline
2. Opening tweet
3. Thread structure
4. Tweet-by-tweet draft
5. Key takeaways
6. Strong lines
7. CTA
8. Alternative opening versions
9. Short version
10. Risky wording to avoid

## Process

1. Clarify the main opinion.
2. Sequence supporting points for continuity.
3. Draft tweet-by-tweet content.
4. Add strong lines, takeaways, CTA, and short version.
5. Flag unsupported data, experience, or performance claims.

## Quality Bar

- Main opinion is clear.
- Each tweet is concise.
- Thread has forward momentum.
- Does not invent data or cases.
- Does not fake personal experience.
- Fits personal brand expression.

## Example Input

Topic: what solo app builders get wrong about AI coding tools
Audience: indie hackers and AI-assisted developers
Main opinion: AI coding tools are strongest when paired with narrow product scope
Thread length: 8 tweets

## Example Output

Opening tweet: AI coding tools do not fix vague product thinking. They amplify it.

## Safety / Compliance Notes

Do not invent metrics, case studies, founder experience, revenue, followers, or audience feedback. Avoid plagiarism and deceptive growth tactics.
