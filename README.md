# Creator Skill Pack

## English

Creator Skill Pack is an open-source AI workflow skill pack for content creators. It helps creators plan and produce platform-ready content across personal brand positioning, content calendars, short video hooks, YouTube scripts, Xiaohongshu posts, and X/Twitter threads.

It is designed for YouTube creators, TikTok creators, Xiaohongshu creators, X/Twitter writers, newsletter authors, indie developers, AI tool educators, ecommerce content creators, outdoor gear creators, and knowledge creators.

This pack is not for spam content, fake engagement, fabricated audience feedback, plagiarism, deceptive clickbait, or guaranteed growth claims.

## 中文

Creator Skill Pack 是一个面向内容创作者的开源 AI 工作流 Skill Pack，用于帮助创作者完成个人品牌定位、内容日历规划、短视频 Hook、YouTube 脚本、小红书笔记和 X/Twitter 长帖生成。

它适合 YouTube 创作者、TikTok 创作者、小红书博主、X/Twitter 内容创作者、Newsletter 作者、独立开发者个人 IP、AI 工具教程博主、电商内容创作者、户外装备博主和知识型创作者。

它不适合批量生成低质量垃圾内容、伪造互动数据、伪造粉丝反馈、搬运抄袭、制造恶意误导标题党，或承诺爆款、涨粉、变现和平台审核通过。
